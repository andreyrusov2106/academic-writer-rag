# 🎓 Academic Writer RAG Assistant

Интеллектуальный помощник для исследователей, аспирантов и студентов, разработанный в роли **профессора Н.П. Копцевой** (доктор культурологических наук). Система анализирует загруженные научные PDF-документы и при необходимости обращается к открытым научным репозиториям (OpenAlex) для предоставления точных, академически выверенных ответов с цитированием источников.

## ✨ Возможности
- 📄 **Загрузка и анализ PDF**: Автоматическое разбиение на чанки, векторизация и семантический поиск по вашим документам.
- 🌐 **Агентный поиск в OpenAlex**: Если локальной базы недостаточно, система автоматически находит высокоцитируемые рецензируемые статьи по теме.
- 🔐 **Система авторизации и лимитов**: JWT-аутентификация, учет запросов, разделение на тарифы (Free/Pro).
- 🧠 **Умные действия с текстом (Smart Actions)**: Научный рерайт, перевод на китайский с терминологией, поиск источников для выделенного фрагмента.
- 📚 **Строгое цитирование**: ИИ отвечает СТРОГО на основе предоставленного контекста, минимизируя галлюцинации.

## 🛠 Технологический стек
- **Backend**: Python, FastAPI, Uvicorn/Gunicorn
- **База данных**: PostgreSQL (с расширением pgvector для семантического поиска)
- **ML/Embeddings**: `sentence-transformers` (multilingual-e5-small)
- **LLM**: DeepSeek API
- **Frontend**: Vanilla JS, HTML5, CSS3, Quill.js (Rich Text Editor)

## 🚀 Быстрый старт (Локально)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/academic-writer-rag.git
   cd academic-writer-rag```
2. Создайте виртуальное окружение и установите зависимости:   
	```bash
	cd backend
	python -m venv venv
	source venv/bin/activate  # Для Windows: venv\Scripts\activate
	pip install -r requirements.txt```
3. Настройте переменные окружения:
	```bash
	cp .env.example .env
    # Отредактируйте .env, добавив свой DEEPSEEK_API_KEY и пароль от БД```
	
4. Убедитесь, что в PostgreSQL создано расширение vector и таблица users.
5. Запустите сервер:
	```bash
	uvicorn rag_api:app --reload --host 0.0.0.0 --port 8000```
5. Откройте frontend/academic-writer.html в браузере.
## 🌐 Деплой на VPS
Проект готов к развертыванию на Linux-сервере (Ubuntu 22.04+) с использованием Nginx и systemd. Подробная инструкция доступна в разделе Deployment (можно добавить позже).
